# MediCare Elite — World-Class Hospital Website

A stunning, fully responsive hospital website built with **Next.js 16**, **Framer Motion** animations, and **HD Unsplash imagery**.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Animations:** Framer Motion
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Images:** Unsplash HD
- **Language:** TypeScript
- **Deployment:** Vercel

## Features

- Animated hero section with HD medical imagery
- Framer Motion scroll-triggered animations throughout
- Animated stat counters (150K+ patients, 500+ doctors…)
- 8-specialty services grid with hover effects
- 6 doctor profiles with availability badges
- Interactive testimonials carousel (5 global patients)
- Appointment booking form with success state
- Contact section with location cards
- Sticky glassmorphism navbar
- Mobile-responsive hamburger menu
- Scroll-to-top button
- CSS gradient animations

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npx vercel
```
